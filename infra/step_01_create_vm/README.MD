# Setup VM

1. Configure OCI
    - see [SDK config](https://docs.oracle.com/en-us/iaas/Content/API/Concepts/sdkconfig.htm) for configuration instructions.

2. Setup Pulumi
    - see [Pulumi installation](https://www.pulumi.com/docs/get-started/install/) for installation instructions.
    - see [Pulumi OCI provider](https://www.pulumi.com/docs/reference/pkg/oci/) for provider configuration instructions.

3. Run the following command to create the VM:

    ```bash
    pulumi up
    ```
